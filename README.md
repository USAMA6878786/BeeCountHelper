# BeeCountHelper for 蜜蜂记账


**点一下控制中心，把当前屏幕记成一笔账。**


蜜蜂记账有个自动记账功能：只要检测到系统截图就去识别记账。

随手截个图也会变成一笔脏账。


这个模块把主动权交回给你——**只有你点「记账」磁贴那一下，它才记账。**

## 它能做什么


- **想记才记**　平时的截图（电源键、三指、长截屏）不再产生脏账

- **一下就好**　下拉控制中心点磁贴，面板自动收起、自动截图、自动交给蜜蜂记账

- **连点不丢**　连续点几下就排几张，逐个识别记账，一张不漏、也不会重复记

- **相册不乱**　识别完成后自动把这张截图删掉，不想要可以在设置里关掉

- **桌面看账**　桌面小组件显示今日 / 本周 / 本月支出，白底、透明度可调

- **也能更快**　可选的截图加速：先压成 JPEG 再交给蜜蜂记账，上传识别更快（首次会静默校准一次）

- **不用先打开它**　蜜蜂记账被划掉、被强制停止都没关系，点磁贴照样记账，全程不弹界面

- ⚠️ **必设「无限制」**　务必把蜜蜂记账的省电策略设为「无限制」，否则系统每 5 秒左右冻结它一次、识别频繁失败

## 要求


Android 8.0 以上，已装 LSPosed，手机有 root。


---


## 安装


1. 下载并安装 APK

2. 打开 **LSPosed** → 启用「BeeCountHelper」→ 作用域勾选「蜜蜂记账」

3. 打开一次**蜜蜂记账**（v2.75 起它不需要 root 了，只走识别）

4. 进蜜蜂记账的「智能记账」，确认**截图自动记账是开着的**

5. 授予「BeeCountHelper」root权限；打开「BeeCountHelper」：再点「添加」把磁贴放进控制中心

6. **必须**把蜜蜂记账的省电策略设为「无限制」（系统设置 → 应用 → 蜜蜂记账 → 省电策略），否则识别会失败


> 更新模块后，请点一次设置页的「重启蜜蜂记账」，新功能才会生效。

>

> ⚠️ **必须把蜜蜂记账的省电策略设为「无限制」**，否则系统会冻结后台的蜜蜂记账、掐断它到 AI 的连接，导致「识别失败」。

## 使用


**记一笔**

下拉控制中心 → 点「记账」→ 完事。连点几次也可以，每张都会单独识别记账，不会丢也不会重复。


**加小组件**

长按桌面空白处 → 添加小部件 →「记账支出」。


**调透明度**

设置页的滑块会应用到所有小组件。

## 常见问题


**点了磁贴没反应？**

先点设置页的「root 权限」确认是否已授权；再把蜜蜂记账重启一次（设置页有按钮），

然后进它的「智能记账」确认截图监听是开着的。


**改了设置没生效？**

点「重启蜜蜂记账」即可。


**提示「识别失败」？**

根因是系统每 5 秒左右冻结一次后台的蜜蜂记账，冻结瞬间掐断它到 AI 的连接（网络报错）。

识别一次要 3~8 秒，期间几乎必然撞上一次冻结，所以这不是偶发、不设对就会频繁失败。

**必须把蜜蜂记账的省电策略设为「无限制」**（系统设置 → 应用 → 蜜蜂记账 → 省电策略），设成之后系统就不再冻结它，识别失败才会消失。

## 权限说明


| 权限 | 用来做什么 |
|---|---|
| root | 截图、收起控制中心、删除截图、重启蜜蜂记账 |
| 读取照片 | 判断截图是否已保存，加快确认速度 |
| 悬浮窗 | 让「截图成功」的提示在后台也能显示 |
| 联网 | **只用于「检查更新」**：你主动点它时，向 GitHub 查一次最新版本号 |


**不收集、不上传任何数据。**

唯一会联网的地方是「检查更新」——只有你点击时才会访问 GitHub 的公开接口读取最新版本号，

请求里只带一个 GitHub 强制要求的 User-Agent（其中含当前版本号），

**不带账本、截图、设备信息或任何标识**。除此之外模块不联网。

> 如果你从 LSPosed 在线仓库安装，更新由 LSPosed 管理器负责，可以完全不点模块里的「检查更新」。
